## 项目简介

AniLink 是一款 [Obsidian](https://obsidian.md/) 追番整合插件。桌面端将番剧检索、字幕组 RSS、本地下载、弹幕、播放、观看进度和 Bangumi 评价集中在一个页面。移动端沿用相同的番剧卡片、观看进度、评价和番剧信息面板，番单单列展示，点击进入竖排详情。

Windows 使用完整桌面功能。macOS、Linux 支持服务连接、本地播放器启动及对应平台的 rclone 组件安装，开机调度与空闲退出管理目前适用于 Windows。移动端保留通用、页面、Bangumi 同步和 WebDAV 远程服务设置，以及作者主页、赞助与反馈。桌面下载器、本地播放器与弹幕处理入口在手机上隐藏。macOS、Linux 和实体手机的端到端运行仍待实机验证，移动入口已通过禁止加载 Node.js、Electron 模块的自动化测试。

- **统一书架**：季度、追番状态、标题筛选与最近更新排序，展示本地可观看的分集。
- **订阅与下载**：在插件中查找蜜柑字幕组，选择语言、编码及字幕版本，交给 qBittorrent 管理 RSS 与下载。
- **弹幕与播放**：从配置的 Bilibili UP 主匹配分集，获取并合并 XML 弹幕；可先校准时间偏移再启动播放器。
- **进度与评价**：手动“看到这里”，维护 Bangumi 收藏状态、评分和短评，后台队列推送修改。
- **番剧信息**：切换 Bangumi、番库、评分趋势预览，也可以打开对应网页。

## 当前功能与设置

- 通用设置提供操作日志范围、保留时间和默认番剧选择。
- Bangumi 支持收藏、进度、评分、短评推送与拉取，以及定时同步和冲突选择。镜像开关同时切换网页和 API 服务。
- qBittorrent 保存每部番剧的 RSS 规则，可配置登录检查和下载完成后的空闲退出。
- 字幕组选择提供独立的自定义搜索。自定义 RSS 提供保存目录、开始状态、重复间隔和资源更新策略。
- qBittorrent 中的“有 v2 版本自动替换未看视频”默认开启。自定义 RSS 可选择跟随全局设置或为单部番剧覆盖规则，已看集和多集种子保留保护。
- 本地管理提供媒体库路径、“点击看到这里”的三档清理操作和删除种子开关。远程库通过 rclone 访问，可选 Kodi、Jellyfin、Emby 播放控制。
- bilibili 支持账号资料展示、官方番剧弹幕合并、UP 主来源和屏蔽规则同步。

### 使用资源更新策略

在 qBittorrent 设置中切换“有 v2 版本自动替换未看视频”，也可在每个订阅的“自定义 RSS”中单独覆盖。开启“自动刷新 RSS 订阅”后按分钟设置的间隔请求下载器刷新订阅，插件运行期间检查资源更新策略。自动替换只处理能唯一映射的未看分集，关联其他分集的种子会保留。Obsidian 关闭期间运行 qBittorrent 自身规则。

插件仍在持续完善，网络服务、浏览器预览和播放器兼容性可能因环境而异。欢迎提供最小复现步骤，勿在公开反馈中上传 Token、Cookie 或完整私人日志。

## 快速入门

### 出厂默认设置

- 网页通过 Obsidian Web viewer 打开，进入插件时打开当前书架排序中的第一部番剧。
- 显示标题原文及番剧信息面板，默认预览番库，书架使用自动列数、全部季度和最近更新排序。
- 日志记录全量操作，退出后清除。Bangumi 启动与退出同步默认开启，定时同步默认关闭，冲突处理采用“询问”。“看到最后一集自动标记看过”默认开启，全部正篇已看且分集数量达到已知总集数时，将收藏状态改为看过。
- qBittorrent 插件自动刷新及下载完成通知默认关闭，刷新间隔预设 1 分钟，空闲退出预设 5 分钟，未看视频修订版自动替换默认开启。
- 本地管理中的“点击看到这里”默认选择“清理已看文件”，删除文件时同步删除对应种子。使用前请按自己的保留视频习惯调整。
- 播放前校准、官方弹幕、港澳台来源及删减校准默认开启，港澳台来源仍需匹配的网络环境，远程服务默认关闭。
- 默认 UP 主为 `4262884,5306996,690151424,154244413,442715778,3546957240862932`。可自行增删，屏蔽词库初始为空。

账号、密码、Token、Cookie、个人播放器与下载路径、远程连接资料不包含在出厂配置中。WebUI 初始地址为 `http://127.0.0.1:8080`。升级时优先保留已有个人配置，出厂默认值只补齐缺失设置。Windows 开机启动项由用户主动开启。

### 安装插件

可在 Obsidian 社区插件市场搜索 **AniLink** 安装，也可从 [GitHub Releases](https://github.com/beimohai/AniLink-Obsidian/releases/latest) 下载 `main.js`、`manifest.json`、`styles.css`，放入库的 `.obsidian/plugins/anilink/`，重新加载 Obsidian 后启用 AniLink。

1.0.1 起音频校准脚本内置于 `main.js`，首次校准时写入插件目录。Windows 开机启动与空闲退出脚本同样内置，使用相关功能时写入插件目录。更新时保留个人配置与媒体文件。

### 依赖安装与连接配置

从 Obsidian 设置中打开 AniLink，按需配置所用服务。设置修改后自动保存。AniLink 不需要其他 Obsidian 社区插件。

| 功能 | 依赖与安装 | 连接配置中的操作 |
| --- | --- | --- |
| 基础运行 | [Obsidian](https://obsidian.md/) ≥ 1.15.0。安装并启用 AniLink。 | 移动端支持书架、进度、评价、番剧信息和 WebDAV 远程目录。 |
| 书架、搜索与评价同步 | [Bangumi](https://bgm.tv/) 账号和 Access Token。通过“获取 Token”打开授权页后复制令牌。 | 将令牌粘贴到 **Bangumi → 访问令牌**。令牌属于私密凭据，不应分享或提交到仓库。插件的搜索、分集和收藏同步使用官方 v0 API 或启用的兼容镜像 API。 |
| RSS 下载 | [qBittorrent](https://www.qbittorrent.org/) Windows 版。安装后在“工具 → 选项 → Web UI”启用 Web UI，并自行设定端口、用户名和密码；RSS 功能保持启用。 | 填写 Web UI 地址、程序路径、用户名、密码和下载目录。默认地址为 `http://127.0.0.1:8080`。后台 RSS 刷新按开关和间隔执行，检查与刷新不会自行启动下载器。订阅或下载操作可以启动已配置的本机下载器。 |

| 弹幕偏移纠正 | 安装 [Python](https://www.python.org/downloads/windows/) 并勾选加入 PATH；安装 [FFmpeg](https://ffmpeg.org/download.html) 后将其 `bin` 目录加入 PATH。 | 在 **播放器与弹幕 → 依赖状态** 点击“检查依赖”。NumPy 缺失时可点击“安装 NumPy”，插件将执行 `python -m pip install --user numpy`；FFmpeg 是系统级软件，插件只检查，不会静默安装。该功能仅在播放时抓取弹幕时执行，可随时关闭。 |
| Bilibili 弹幕来源 | Bilibili 登录会话；部分搜索、音轨或弹幕访问可能要求登录并受服务端风控影响。 | 在 **bilibili** 区登录，并按需填写限定的 UP 主 UID。登录过期后重新登录。 |
| 远程媒体库 | WebDAV、SFTP、FTP/FTPS 或 SMB 服务及访问账号。 | 在 **远程服务** 开启后填写地址、账号和远程目录，通过检查连接确认可访问。 |
| rclone | 在远程服务中按需点击“安装组件”，插件下载官方对应平台版本。 | 用于远程目录浏览、扫描和媒体读取，适用于已开启的远程服务。 |
| 网络播放器 | Kodi，或已在线的 Jellyfin / Emby 客户端。 | 开启远程服务后，在 **播放器与弹幕** 填写服务地址、访问密钥和媒体路径。Jellyfin / Emby 另需客户端会话 ID。 |

Bangumi 设置中的“使用镜像网站”同时切换网页至 `bangumi.lat`、API 至 `api.bangumi.lat`，关闭时使用官方域名。镜像列表由 [bangumi.wiki](https://bangumi.wiki/api/v1/mirrors) 提供，镜像服务会接收同步所需的访问令牌和数据。

建议为 AniLink 使用独立媒体目录，不要将个人文档或多个番剧混放在同一番剧目录内。自动清理会实际删除媒体文件。

## 追番全流程

1. **添加番剧**：搜索中文名、日文名或 Bangumi ID，选择“在看”等状态加入书架。已有书架条目直接打开；Bangumi、番库按钮用于网页访问。
2. **选择版本**：进入字幕组查找，选择正确季度与字幕组，查看语言、编码和字幕形式；需要时填写自定义 RSS。自动下载会按已看进度跳过前面的集数。
3. **等待更新**：qBittorrent 运行期间按 RSS 设置检查更新并下载，插件轮询下载情况。本地已下载的未看分集显示待看提示；官方播出日期不代表字幕资源已经可用。
4. **播放分集**：选择本地分集并播放。插件尝试匹配限定 UP 主的相应集数，获取弹幕；启用校准时逐来源比较音轨、调整时间后合并 XML，再启动播放器。首次处理耗时受网络、来源数量和文件长度影响，不能保证即时完成。
5. **确认进度**：看完后点击“看到这里”，此前普通分集一并标为看过，立即反馈并选中下一集，后台执行已配置的文件清理。仅打开视频不会自动标记看完，避免半途退出造成误标。
6. **同步评价**：选择追番状态、评分与短评并保存，修改进入 Bangumi 后台同步队列。在 Bangumi 设置中推送或拉取，在通用设置中查看日志。
7. **收尾清理**：本地管理中的“点击看到这里”控制不清理、清理当前文件或清理已看文件。最后一集的收藏状态由 Bangumi 中的“看到最后一集自动标记看过”控制。弃番沿用独立目录和 RSS 清理流程，搁置暂停订阅并保留文件。

### 下载器运行方式

RSS 规则保存在 qBittorrent，只有下载器运行时才会检查与下载。Obsidian 关闭后插件自身不会继续轮询。手动下载可在已配置程序路径时尝试启动下载器。

qBittorrent 设置提供 Windows 登录启动开关，以及检查订阅、下载完成退出和空闲退出设置。启用登录启动时插件创建 Windows 启动项，运行时由随插件分发的 PowerShell 调度脚本执行。Obsidian 关闭后已配置的启动项仍可运行。

### 片头音频校准

校准只读取来源与本地视频开头 180 秒。首次比较 3 个采样点，出现异常或置信度不足时最多补采 1 轮、3 个点，每个来源最多 6 个采样点。至少 3 个可靠采样点的偏移保持一致才合并该来源弹幕，额外拼接的视频尾部不会参与计算。单次音频读取超时为 45 秒，整次校准进程超时为 120 秒。

### 手机端远程播放

手机端通过 WebDAV 浏览和扫描媒体库，无需 rclone。视频在内嵌播放器中打开，也可打开视频网页。受账号认证保护的直链需要浏览器可使用的登录会话，支持的封装和音视频编码取决于设备。手机端无法执行桌面 qBittorrent、Python、FFmpeg 或本地播放器程序。真实手机、macOS、Linux 的端到端验证仍待完成。

### 官方弹幕与删减时间

“播放器与弹幕”中的“启用官方番剧弹幕”会将正版弹幕与 UP 主来源合并。“启用港澳台弹幕”单独控制区域来源，访问取决于当前网络出口和账号权限。支持《异世界舅舅》与官方名称《奇幻世界舅舅》的对应。播放准备期间显示处理状态，Windows 本地播放器启动后会尝试移至主屏并置前。

官方弹幕采用 [AniClip](https://github.com/bili-vd-bak/aniclip) 的删减时间数据，核对集数与来源 CID 后，对有时长的视频删减片段分段延后弹幕。画面替换条目保持原时间。该对齐以本地视频保留被删片段为前提，视频旁仅保留一份同名 XML，成功生成弹幕后更新文件。数据覆盖范围和准确度由上游决定，原数据由汇总酱整理并按 CC BY-NC-SA 4.0 许可提供。

## 自定义与数据管理

- 在插件设置中调整默认季度与排序、搜索状态按钮、网页打开方式及番剧信息默认页面。
- 连接地址、程序路径、媒体目录与 UP 主来源按设备配置；音频校准和自动清理按观看习惯调整。
- 完整状态保存在库内 `.obsidian/plugins/anilink/data.json`，包括书架、进度、评价、订阅、连接凭据与待同步队列。旧版 `%LOCALAPPDATA%/AniLink/` 数据在首次升级时自动迁入，旧文件保留供恢复。复制插件目录会带上完整数据。凭据没有加密，请只同步到自己的私人空间。
- 多设备进度按字段合并，适用于由自己的同步工具同步插件数据。设备本地标识用于区分修改来源。完整 data.json 也包含连接资料，请仅同步至自己的私人空间。
- 视频及 XML 位于指定媒体目录；网页登录由 Electron 会话保存。备份和清理共享数据时请阅读 [隐私与安全](SECURITY.md)。

## 常见问题与边界


**刷新会启动或检查下载器吗？** 不会。刷新会更新本地媒体和同步状态，已启用的资源修订规则可检查正在运行的下载器。后台 RSS 刷新由独立开关控制，下载器关闭时不会由刷新动作自动启动。

**网页预览打不开？** 预览依赖 Obsidian Web viewer、站点嵌入限制、登录会话和网络。可切换默认浏览器打开；番库无法确定条目时可能退回检索页，不保证所有译名与续季均能唯一关联。

**B站返回 412？** 这是服务端风控，登录会话不保证解除。减少请求、稍后重试或重新测试登录状态；插件不保证每个来源始终可访问。限定 UP 主检索也不等于已经遍历其全部合集与分 P。

**偏移是否一定能校准？** 当前处理音轨间的一致时间偏移，不支持所有剪辑、分段删减或变速版本。结果不可信时会报错，不应把错误偏移写入弹幕。可在设置中关闭校准。

**为何需要系统权限？** 插件直接读取外部媒体目录、生成 XML、按设置删除媒体，通过子进程启动播放器与音频校准程序；粘贴按钮在点击时读取剪贴板。这些是桌面功能所需，不代表 Obsidian 的安全审查已豁免。不要加载来源不明的 RSS 或配置。

## 开发与构建

```bash
npm ci
npm run build
npm run lint
npm test
npm run check
npm run package
```

使用 Node.js 24 与已提交的锁文件。`src/` 为界面及整合源码，`core.js` 为核心逻辑，`scripts/align-audio.py` 为独立音频校准实现。构建生成根目录 `main.js`；本地安装包生成在 `dist/anilink/`。更多内容见 [开发说明](docs/DEVELOPMENT.md) 与 [测试说明](docs/TESTING.md)。
