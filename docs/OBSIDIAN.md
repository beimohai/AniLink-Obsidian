# Obsidian 社区目录介绍

- ID 为 anilink，名称为 AniLink，作者为北漠海。
- 中文简介为“番剧检索、RSS 订阅下载、媒体播放与弹幕，支持 Bangumi 收藏、观看进度和评价同步。”。
- 仓库为 beimohai/AniLink-Obsidian，最低 Obsidian 版本为 1.15.0。
- manifest 的 isDesktopOnly 为 false，手机端使用共享界面与平台适配实现。

项目已收录于社区插件目录。目录当前标注插件尚未经过 Obsidian 工作人员手工审核。收录状态可在 [官方目录](https://github.com/obsidianmd/obsidian-releases/blob/master/community-plugins.json) 查询。

发行标签使用与 manifest.version 完全相同的版本号，例如 1.0.12。发布附件为 main.js、manifest.json 和 styles.css，GitHub Actions 为这三个文件生成构建来源证明。音频和调度脚本内置于 main.js。
