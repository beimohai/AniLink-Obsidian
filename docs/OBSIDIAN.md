# Obsidian 社区目录介绍

- ID：anilink
- 名称：AniLink
- 作者：北漠海
- 简介：Manage anime subscriptions, local downloads, playback, and Bangumi progress and reviews.
- 仓库：beimohai/AniLink-Obsidian
- 桌面端：是，当前支持Windows
- 最低版本：1.15.0

GitHub Release提供安装文件。社区插件目录收录需要向obsidianmd/obsidian-releases单独提交并通过审核。当前尚未收录。音频校准额外需要Python、NumPy、FFmpeg，其他播放器弹幕扩展兼容性见README。
