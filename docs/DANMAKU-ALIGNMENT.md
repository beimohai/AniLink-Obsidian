# 音频与弹幕校准

逐来源读取来源与本地视频开头 180 秒，进行频谱匹配。首次取 3 个片头采样点，异常或置信度不足时最多再取 3 点，每个来源上限为 6 点。至少 3 个可靠采样点的偏移须落在 0.15 秒范围内，可靠点的中位匹配度须达到 0.6。存在另一组同样得到三个点支持的冲突偏移时，拒绝该来源。

音轨每次读取限制为 45 秒，校准子进程限制为 120 秒。重新采样只执行一次，失败后保留错误信息。参考视频尾部的额外拼接内容不会参与校准。

来源弹幕应用确认的偏移后合并至视频旁的同名 XML。XML 保留来源标识，选项或算法版本改变时重新生成。运行需要 Python、NumPy 和 FFmpeg。

官方番剧的删减时间使用 AniClip 数据，核对集数与来源 CID 后按时长调整。画面替换保持原时间。音频校准负责统一偏移，任意剪辑产生的多段偏移仍需对应的删减时间资料。
