# 开发验证

使用 Node.js 24 与锁文件执行 npm ci、npm run build、npm run lint、npm test、npm run check、npm run package。音频算法另外运行 python tests/test_audio_alignment.py，需要 NumPy。CI 同时运行 JavaScript 和 Python 回归测试。

Checks 工作流使用 Windows、macOS 和 Linux 三个平台。平台专用调度器在 Windows 测试中运行，其他系统验证通用代码、构建及导入边界。1.0.13 增加推荐警告统计以及不导入 Node 的移动分集匹配测试。

## 功能覆盖

| 功能 | 验证方式 |
| --- | --- |
| Bangumi 搜索、收藏、评价与逐集进度 | 回归测试、离线队列、并发修改和错误重试 |
| 蜜柑搜索与 RSS 规则 | 来源 ID 核验、语言/画质/编码匹配、版本更新、异常候选页 |
| 下载器启动、抓取及空闲退出 | Windows 脚本测试及本机入口验证 |
| 本地文件与媒体库 | 临时目录测试、手动关联、保留未看文件、视频与 XML 联动 |
| 播放与弹幕 | 播放器启动路径检查、来源核验、官方弹幕、过滤及片头校准测试 |
| WebDAV 与其他远程协议 | 地址及路径验证、扫描结果对账、失败保留、平台入口检查 |
| 多设备数据 | 迁移、坏数据保护、字段合并、已推送编辑、设备连接保留 |
| 手机与平板界面 | 移动入口、禁止 Node/Electron 导入、多尺寸布局及滚动检查 |
| 预览、设置、通知与发布文件 | 事件状态、实际预览、版本日期一致性及可复现构建 |

测试覆盖订阅规则、季度与分集匹配、离线进度、清理保护、同名脚本内置、构建复现、存储迁移、移动端导入边界和逐字段合并。音频测试覆盖尾部拼接、异常点重采样、短音频和无关音轨拒绝。

真实服务测试在自己的专用库进行，凭据、日志、截图和结果保存在已忽略目录或仓库外。部署替换 main.js、manifest.json、styles.css，保留 data.json。

Windows 上已进行设置布局、观看进度、遗留文件清理和片头音频校准验证。实体手机、macOS、Linux、受认证保护的远程视频及所有第三方播放器组合仍需对应设备验证。
