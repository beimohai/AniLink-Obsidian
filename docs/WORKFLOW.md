# 追番流程

配置连接与本地路径 → 搜索加入在看 → 选择字幕组订阅 → 下载完成自动关联 → 获取并校准弹幕 → 播放 → 手动看到这里 → 同步进度、评分和短评。

点击“看到这里”立即更新进度并选中下一集。本地管理中的“点击看到这里”控制文件清理操作，视频与对应弹幕一起处理。下载器任务已移除时，插件确认任务不存在并核对库内路径后清理遗留文件。

Bangumi 中的“看到最后一集自动标记看过”默认开启，全部正篇已看且分集数量达到已知总集数时生效。弃番沿用独立目录和 RSS 清理流程，搁置暂停订阅并保留文件。

手机端使用单列番单与竖排详情，支持观看进度、评价、番剧信息和 WebDAV。桌面下载与音频处理操作在手机上隐藏。多设备使用私人同步服务传输插件 data.json，各自核对本机路径和连接资料。
