# 发布检查处理情况

## 已处理

- authorUrl 改用作者 GitHub 主页，避免 Bilibili 主页对检查器的访问限制。
- 刷新按钮不再调用禁用／启用插件接口，改为刷新任务、数据与视图；不再执行插件生命周期重启。
- 浏览器侧计时器显式使用 window；测试沙箱补齐对应浏览器接口。
- 清理无效表达式、未使用变量，明确可选操作失败时保留状态的空 catch。
- README 增加英文简介、完整安装配置说明、权限用途、赞助与反馈。
- 构建输入统一 LF，避免 Windows 与 Linux 换行差异；CI 使用锁文件和固定 Node 主版本。
- 音频脚本内置 main.js，发行工作流只上传三种标准文件，并为它们生成 GitHub 构建来源证明。

## 尚未全部消除

- no-unsafe-*：现有 CommonJS JavaScript 缺少完整类型声明。需要逐模块添加数据接口、接口响应验证与 Obsidian 类型后才能全面通过；没有通过关闭审查器规则隐藏问题。
- require 风格：当前为 CommonJS 构建和运行结构；改为 ES module 源码需要同步调整构建和模块测试，尚未迁移。
- 声明式设置搜索：设置当前通过动态 display 界面实现，尚未迁移 getSettingDefinitions，不影响现有设置保存，但不提供全部设置搜索能力。
- CSS !important、:has 与 webview 类型选择器仍存在。它们参与当前布局、Electron 网页容器及覆盖样式，未批量替换，以免造成布局回退。性能与视觉需按选择器逐项实测。
- 文件系统、子进程、剪贴板访问是外部视频、播放器、音频校准和粘贴功能所需。已在 README 和 SECURITY 中说明，权限提示仍会存在。

以上不等于 Obsidian 官方审核通过。单元测试与静态检查也不替代真实网络、网页与播放器端到端测试。
